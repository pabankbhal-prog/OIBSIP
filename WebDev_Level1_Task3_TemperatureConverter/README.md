# 🌡️ Temperature Converter

A modern and responsive **Temperature Converter** web application developed using **HTML5, CSS3, and JavaScript**. This project allows users to convert temperature values accurately between **Celsius (°C)**, **Fahrenheit (°F)**, and **Kelvin (K)** through a clean, user-friendly interface.

---

# 📖 Project Description

The Temperature Converter is designed to perform quick and accurate temperature conversions using JavaScript. It provides a simple interface where users can enter a temperature value, select the source unit and target unit, and instantly view the converted result.

The application also validates user input and prevents invalid temperature values such as temperatures below absolute zero, ensuring reliable and meaningful conversions.

---

# ✨ Features

- 🌡️ Convert Celsius to Fahrenheit
- 🌡️ Convert Celsius to Kelvin
- 🌡️ Convert Fahrenheit to Celsius
- 🌡️ Convert Fahrenheit to Kelvin
- 🌡️ Convert Kelvin to Celsius
- 🌡️ Convert Kelvin to Fahrenheit
- ✅ Real-time temperature conversion
- ✅ Input validation
- ✅ Absolute zero validation
- ✅ Reset functionality
- ✅ Responsive design
- ✅ Modern and attractive user interface
- ✅ Compatible with desktop, tablet, and mobile devices

# ▶️ How to Use

1. Open the application in your web browser.
2. Enter a temperature value.
3. Select the source temperature unit.
4. Select the target temperature unit.
5. Click the **Convert** button.
6. View the converted temperature instantly.
7. Click **Reset** to clear all fields.
